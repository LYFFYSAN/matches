## برنامج الحراسة — تشغيل التطبيق

### المتطلبات
```
PyQt5>=5.15
matplotlib>=3.5
```

### التثبيت
```bash
pip install PyQt5 matplotlib
```

### التشغيل
```bash
python supervision_app.py
```

### الميزات
- لوحة تحكم مع إحصائيات ومخططات بيانية
- قائمة الأساتذة مع بحث وتصفية وإضافة وحذف
- جدول الحراسة الكامل مع فلاتر
- إضافة جلسات جديدة
- إحصائيات مرئية (مخططات أعمدة ودائرية)
- كشف التعارضات التلقائي
- تصدير: CSV عادي + CSV لـ SPSS + تقرير TXT
