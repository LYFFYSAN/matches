🔍 Video Auto-Finder

Search Scorebat's free API for embeddable football highlights — no geo-restrictions

📋 How to use in your admin panel
  1. Search for a match above (e.g. "Algeria" or team names)
  2. Find a working video — click 👁 Preview to test it
  3. Click 📋 Copy Embed URL
  4. Go to your admin panel → match → Add Video → paste the URL in Embed URL
  5. Set Platform to Scorebat, save ✅
